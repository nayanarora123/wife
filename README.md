# 💍 Love Story — Nayan ❤️ Charan

A premium, romantic interactive love-story website with a full admin panel.

## 🚀 Quick Start

```bash
cd love-story
npm run dev
```

Open:
- **Love Page**: http://localhost:3001/love/nayan-charan
- **Admin Panel**: http://localhost:3001/admin/login
  - Email: `admin@love.local`
  - Password: `love1234`

---

## 📦 Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v3 |
| Animation | Framer Motion |
| Database | Supabase (PostgreSQL) |

---

## 🔧 Supabase Setup

1. Create a project at [supabase.com](https://supabase.com)
2. Run `supabase/migrations/001_initial.sql` in SQL Editor
3. Update `.env.local` with your project URL and keys

---

## 💍 Special Features

- **Tap to Enter** with floating hearts
- **Love Letter** envelope animation
- **Live Counter** — seconds-accurate relationship timer
- **Marriage Game** — NO button runs away on mobile touch!
- **YES Celebration** — Canvas confetti + fireworks
- **Moon Phase** — SVG calculated from relationship date
- **Spin Wheel** — Weighted random with canvas physics
- **6 Theme Presets** + full custom colors
